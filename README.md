# LiveStream（ライブ配信サイト プロトタイプ）

TypeScript で作った、ブラウザだけで配信・視聴できるライブ配信サイトのプロトタイプです。

## 機能

- ブラウザからカメラ配信（WebRTC）
- 画面共有配信
- 画像配信（カメラ・画面共有なしで、好きな画像を映して配信。マイクがあれば音声も乗る）
- 配信中にカメラ / 画面共有 / 画像をいつでも切り替え可能（視聴者の再接続なし）
- スマホからも配信可能（画面共有はスマホのブラウザ非対応のため非表示）
- 美顔補正（カメラ配信のみ。顔認識で顔だけに「肌をなめらかに・明るく」をかけ、目と口はくっきり残す。強さをスライダーで調整、配信中も切り替え可）
- マイクのミュート切り替え
- 配信一覧ページ（3秒ごとに自動更新）
- リアルタイムチャット（配信者のコメントは強調表示）
- 同時視聴者数のリアルタイム表示、配信経過時間

## 動かし方

Node.js 18 以上が必要です。

```bash
npm install
npm run dev
```

本番（Render など）では Build Command に `npm install && npm run build`、Start Command に `npm start` を指定します。

ブラウザで http://localhost:3000 を開きます。

1. 「配信を始める」→「カメラ」「画面共有」「画像」のどれかを選ぶ → タイトルと名前を入れて「配信開始」
2. 表示された視聴用リンクを別タブ（または別ブラウザ）で開くと視聴できます
3. 配信一覧ページ（トップ）にも配信が表示されます

## 構成

```
server/index.ts      Express + WebSocket サーバー（ルーム管理・シグナリング中継・チャット）
shared/protocol.ts   サーバー/クライアント共通のメッセージ型・ICE サーバー設定
client/common.ts     WebSocket ラッパー・チャット UI 共通処理
client/home.ts       配信一覧ページ
client/broadcast.ts  配信ページ（カメラ/画面共有取得、視聴者ごとの WebRTC 接続）
client/watch.ts      視聴ページ
public/              HTML / CSS（client/*.ts は esbuild で public/js にビルド）
```

### 仕組み

```
配信者ブラウザ ──(WebSocket: シグナリング/チャット)── Node サーバー ──(WebSocket)── 視聴者ブラウザ
      └──────────────────── WebRTC で映像・音声を直接送信 ────────────────────┘
```

視聴者が入室すると、サーバーが配信者に通知し、配信者がその視聴者用の `RTCPeerConnection` を作って offer を送ります（SFU を使わない 1 対多のメッシュ構成）。

## プロトタイプの制約と、本番化に向けた次のステップ

| 課題 | 現状 | 対応案 |
|---|---|---|
| 視聴者数の上限 | 配信者が全員に直接送るため、実用は〜10人程度 | SFU（LiveKit / mediasoup）を導入、または大人数向けに RTMP→HLS 配信 |
| NAT 越え | 既定は STUN のみ。会社・モバイル回線では繋がらないことがある | TURN サーバー（coturn / Metered など）を用意し、環境変数 `TURN_URLS`（カンマ区切り）・`TURN_USERNAME`・`TURN_CREDENTIAL` を設定 |
| 他の端末からの接続 | カメラ取得は https か localhost でのみ可能 | HTTPS 化（本番は証明書、開発時は ngrok / Cloudflare Tunnel 等） |
| ユーザー管理 | なし（名前は自由入力） | 認証（Auth.js / Firebase Auth など）、配信者アカウント |
| データ保存 | メモリのみ（再起動で消える） | DB（PostgreSQL + Prisma など）でチャット・配信履歴を保存 |
| モデレーション | なし | NG ワード、BAN、連投制限 |
| サムネイル | ダミー画像 | 配信者側で定期的にキャプチャしてアップロード |
| 録画・アーカイブ | なし | SFU 側で録画、またはクラウドの配信サービス |
